# Portofolio Andin Mohamad Ramdan

Website portofolio statis (HTML, CSS, dan sedikit JavaScript). Tidak perlu build atau instalasi.

## Isi folder

- `index.html`: halaman utama
- `img/`: foto kegiatan
- `.nojekyll`: agar GitHub Pages menampilkan file apa adanya

## Cara upload ke GitHub Pages

1. Buka github.com, klik **New repository**. Beri nama bebas, misalnya `portofolio`, pilih **Public**, lalu **Create repository**.
2. Klik **uploading an existing file**, lalu seret semua isi folder ini (`index.html`, folder `img`, `.nojekyll`, `README.md`). Klik **Commit changes**.
3. Buka **Settings > Pages**. Pada **Source**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu 1 sampai 3 menit. Alamat web Anda: `https://USERNAME.github.io/portofolio/`

Kalau repository diberi nama `USERNAME.github.io`, alamatnya menjadi `https://USERNAME.github.io/`.

## Mengubah isi

Edit `index.html`. Teks ada di bagian `<section>`, foto di folder `img/`.
